# Memoria Progetto: ElettroImpianti-Site

## Descrizione
Sito web moderno e responsive per azienda/professionista nel settore impiantistica elettrica, domotica, sicurezza ed energie rinnovabili (ElettroImpianti).

## Repository Remoto
- **Nome Repository**: `ElettroImpianti-Site`
- **Visibilità**: Pubblico
- **Piattaforma**: GitHub (`manueleesposito77-HAL`)

## Architettura e Tecnologie
- **Struttura**: HTML5 semantico, CSS3 moderno (Custom Properties, Glassmorphism, Responsive Grid/Flexbox), JavaScript vanilla per interazioni e micro-animazioni.
- **Sezioni Principali**:
  - Hero Section con animazioni, indicatori di affidabilità e CTA immediata.
  - Servizi (Impianti Civili/Industriali, Domotica Smart Home, Fotovoltaico, Quadri & Manutenzione, Videosorveglianza & Antintrusione).
  - Punti di Forza / Certificazioni / Statistiche.
  - Sezione Progetti / Portfolio interventi.
  - Modulo di Richiesta Preventivo / Contatto rapido e recapiti.
  - Footer completo con orari, recapiti e crediti.

## Decisioni di Design
- Palette colori: dark mode elegante (nero antracite e blu notte) con accenti elettrici ciano/ambra per richiamare energia e innovazione tecnologica.
- Tipografia: Google Fonts ("Outfit" e "Inter").
